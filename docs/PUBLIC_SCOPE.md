# Evaluation scope

Included: first-party HUGO Kotlin source through the verified H061 baseline,
its existing tests and architecture guards, independently recorded BLE research
implementation, gateway contracts, context/voice/vision boundaries and memory
governance/storage. The new presentation shell exposes only simulation.

Excluded: original Git history, untracked local experiments, personal screenshots,
recordings, account credentials, owner memory, real BLE identity, private machine
paths, decompiled vendor assets and upstream implementation code without a grant.
No pretrained model weights or runtime provider credentials were added.

The original repository and installation stay private and unchanged. This
showcase APK does not connect to a real body, provider or service. The `app`
module retains the original research client, including physical-device adapters
and its original permissions, for source inspection and build/test coverage.
Install only the isolated `showcase` APK for this evaluation; the research
client is not the presentation entry point.

H062+ is not implemented by the showcase. General device compatibility,
multi-body autonomy, self-modifying production software and production readiness
are not claimed. Emulator software checks do not prove physical stopping times,
radio behavior, microphone quality or real-world device acceptance.
