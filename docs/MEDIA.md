# Media, reproducibility and scope

The screenshots are captures of the actual native Compose evaluation app on a
disposable Android 35 x86_64 emulator. Its separate package is
`io.redi.hugo.showcase`. Identity is newly generated locally; all visible memory
envelopes are synthetic. No personal installation or physical robot is shown.

The DE/EN videos are silent captioned montages of these real screenshots, with
an editorial frame. They are not continuous screen recordings and do not show
live language-model reasoning. Every scene labels the simulated body and
scripted proposals. The hero and social card combine real captures with text.

The shell uses the existing safety/E-stop reducers and H061 semantic factories.
It does not replace the production authorization orchestrator, persist the
memory-lab correction, call a provider or demonstrate physical safety acceptance.
The Keystore storage tests are separate from the visible memory lab.

Capture scenario: runtime → pending proposal → approved virtual light → rejected
overspeed → rejected stale command → generation change → local stop → model
candidate → rejected self-validation → user correction draft → architecture.

[media-manifest.json](assets/media-manifest.json) records the original source
revision, capture environment, APK checksum, dimensions, duration, file hashes
and review state. [Product assets](product-assets.json) records unchanged source
artwork and the verified Gradle wrapper. Existing embedded artwork provenance
was preserved. No original private phone screenshot was republished.
