# HUGO Roadmap V2

## M2.5 - HUGO Architecture Migration

Baseline lock, universal identity/capability/provider contracts, manifests, trust/permission contracts, registry, active-body concept, LOOI mapping/facade, dependency guards, and T032 regression proof.

## M3 - Universal Device/Body Runtime

Generic discovery/identity/lifecycle, adapter registry, connection providers, compatibility/negotiation, calibration, provider diagnostics, and provider-instance foundations. LOOI remains Reference Body Adapter #1. A second body is a later portability proof, not an immediate requirement.

## M4 - Personal Context and Integrations

Context Engine, phone/device observations, service connector/auth contracts, dashboard foundation, and one carefully selected read-only integration feasibility path.

## M5 - Voice and AI Agent

Local intent, activation-gated audio, speech contracts, capability-backed skills, provider-neutral gateway, secure auth, bounded context, strict proposal mediation, conversation, and cost/security acceptance.

## M6 - Long-Term Personal Memory and Learning

Seven memory layers, encrypted local storage, validation/reconciliation, bounded retrieval, summaries, privacy, correction/deletion/export, and evidence-bearing strategy learning.

## M7 - Multi-Provider Orchestration

Capability selection across authorized providers, explicit proposals/approvals, bounded cross-provider routines, deterministic cancellation, simulation, and acceptance. No open-ended autonomy.

## M8 - Developer Mode and Adapter Expansion

Structured development needs, sandbox boundary, documented research/licensing policy, adapter proposals, verification, controlled install/enable, rollback, and audit.

## M9 - Higher Autonomy and Product Acceptance

Portable perception/vision foundations, feasibility-gated bounded autonomy, packaging, security/privacy/reliability acceptance, and evidence-supported capability claims.

## Sequencing rule

`HUGO_TASKS.md` is the post-T032 execution backlog. Execute one task at a time. Do not begin voice, AI, memory, multi-provider behavior, or Developer Mode until the prerequisite universal contracts and LOOI regression gates are complete.

## World-model review gate

[World Model, Spatial Reasoning, and Affordances](WORLD_MODEL_AND_AFFORDANCES.md) records accepted future architecture and decomposed coverage gaps across M3/M4/M6/M7/M9. Those gaps require an explicit backlog review; they do not renumber H001-H080 or authorize implementation in H004.
