# HUGO visual identity concepts

These files are visual concept variants for the future animated HUGO face. They are design inputs,
not Android runtime assets yet.

- `hugo-spirit-amber-soft-v1.png` - the first warm, soft-presenting amber-eye concept.
- `hugo-spirit-amber-masculine-v1.png` - a closely related, subtly masculine-presenting variant.
- `hugo-spirit-amber-masculine-v2.png` - the corrected idle variant with level outer eye corners,
  straighter brows, and no visible resting mouth. This is the current preferred masculine concept.

Both images represent the same persistent HUGO. A visual mode or later design revision must never
create or replace `HugoIdentity`, imply a selected body, or grant trust, authorization, safety, or
execution authority. HUGO remains distinct from LOOI and every other body/provider.

FL008 may use these concepts as visual references when implementing the avatar with code-native
Compose/Canvas layers for idle, listening, speaking, discovery, connection, and body-presentation
states. The raster concepts should not be treated as proof of any backend state.
